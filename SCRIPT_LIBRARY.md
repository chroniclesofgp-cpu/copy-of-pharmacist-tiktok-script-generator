1. Save it as `SCRIPT_XX_product-hook.md` in the `/scripts/` folder
2. Deliver it as an attachment in the chat so it appears at the top of your Documents tab
3. Add a row to this index table
4. Update `CONTENT_PIPELINE.md` to move the product from Write Queue to Film Queue
