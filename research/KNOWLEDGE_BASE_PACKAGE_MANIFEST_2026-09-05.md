## BOF Audit Updates

The current BOF template retains the original Types 1–4 fill-in-the-blank structures, five benefit-stack options, caption templates, overlay templates, and quality checklists. It now also states that patient-return, purchase, clinical-outcome, lowest-price, sellout, and discount claims must not be invented or left unverified. Type 4 now explicitly requires real counterfeit, seller-mismatch, or unverifiable-listing evidence for Path A; Path B remains the criteria-led alternative and must not falsely label ordinary competitors as counterfeit. If neither evidence condition is confirmed, Type 4 is skipped.

## Provenance Boundary

These are operating documents and framework cards. They are not raw creator transcripts. Creator-derived claims remain bounded by the source and validation language inside each document. Compliance and violation-history materials were not added to this package unless explicitly part of one of the requested files.
