## HOW PRIORITY IS ASSIGNED

Each product is scored on three signals:

1. **Proof of concept** — Has rphreviews, Riva, or another top creator already made millions of views on this product? If yes, the audience is confirmed and the hook is validated.
2. **TikTok Shop velocity** — Does the product have a large review count or known high-GMV history on TikTok Shop? High review count = high purchase volume = high conversion ceiling for affiliate.
3. **Pharmacist angle exclusivity** — Does the product have a mechanism or angle that no other creator has explained yet? If yes, there is a first-mover advantage.

**Priority tiers:**
- **P1 — Film immediately.** Script written, proof of concept confirmed, high TikTok Shop velocity.
- **P2 — Write and film soon.** Intel doc complete, strong pharmacist angle, no script written yet.
- **P3 — Write next.** Intel doc complete, moderate priority, script not yet started.
- **P4 — Research gap.** No intel doc exists yet. Need research before writing.

### Why Toplux Magnesium is P1 for the Write Queue

The intel doc documents a specific phenomenon: rphreviews and Riva both made essentially the same script on this product and both got millions of views. This is the only product in our library where two top creators independently validated the same hook structure. The symptom-checklist → right-way sequence is proven. The script writes itself from the intel doc. This should be the next script written.

### Why Neuro Gum Version C is P1 for the Film Queue

The Version C script (written Jun 1, 2026) uses the instruction-correction hook with the wasted-effort trigger — "you chewed it for a few seconds and swallowed." This is the MOF audience: people who already bought the gum and were disappointed. That is the highest-intent buyer segment. The script was built with the full 3-doc context + phrase bank injection and is the strongest Neuro Gum script in the library.

### Why SKIN1004 is P2 despite having 4,556 reviews

SKIN1004 has the highest review count in our product library, which confirms high purchase volume. But the script (#20) is a symptom checklist hook — a TOF format — and the product's strongest pharmacist angle (Centella anti-inflammatory mechanism + Korean UV filter education) is a suppressed-knowledge hook that hasn't been written yet. The TOF script should be filmed first to build audience, then the suppressed-knowledge MOF script should be written and filmed second.
