## What Did Not Work / What Should Be Changed

### 1. The "Recommendation" Setup
- **Problem:** Saying "If you're looking for a great recommendation..." does not work for TOF audiences.
- **Quote:** "I wouldn't say 'if you're looking for a good recommendation' either... nobody really knows that they need magnesium when they're coming into this video... they haven't done any other research."
- **Fix:** Frame it as personal use + patient recommendation, not a recommendation to the viewer.

### 2. Verbally Explaining What Each Magnesium Type Does
- **Problem:** The creator verbally explained each magnesium type when the on-screen diagram already showed it.
- **Quote:** "I don't think that's necessary because the diagram already shows that... people will naturally understand 'okay this one is for sleep, this one is for the stomach, this one is for the brain'..."
- **Fix:** Let the diagram do that work. Verbally just name one or two types as examples, then let the visual carry the rest.

### 3. CTA Length
- **Problem:** CTA was ~20 seconds long — too long.
- **Quote:** "Your CTA should be much shorter."
- **Fix:** Condense CTA to social proof + urgency + link. No going back to features during the CTA.

### 4. Mentioning Features During CTA
- **Problem:** Creator went back to mentioning bottle features during the CTA.
- **Quote:** "I think at this point I wouldn't even go back to mentioning the bottle cause you're already doing your CTA. If you were going to mention the benefits of the bottle, that has to be before the CTA typically. Once you start the CTA I don't like to get back into features cause then it really prolongs the ending."

## Frameworks & Rules Mentioned

### The "Remake" Rule
- When remaking a viral video, keep it one-to-one for the first version.
- For variations: test doing ALL symptoms first, then say "those are all signs of high cortisol" — rather than naming cortisol mid-hook.

### Article Popup Psychology
- "Viewers are just going to think that you're summarizing whatever article or image you have up here anyways. Like nobody pauses the video to read the headline or read the diagram... people just continue on with the video listening to you."
- Implication: article popups add credibility passively — you do not need to verbally explain them.

### TOF Psychology — Product Intro
- TOF viewers have not done prior research. Asking if they "want a recommendation" does not work.
- Instead: "straight up saying 'this is the one that I use,' immediately people are just going to trust you because of your credentials."

### CTA Rule
- Once the CTA starts, do not go back to features. Features must come before the CTA.
- CTA = social proof + urgency + link. Keep it short.
