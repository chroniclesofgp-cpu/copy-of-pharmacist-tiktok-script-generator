## 1. What the Source Format Actually Does

The reference is a rapid, single-shot two-person exchange: a person names one highly recognizable frustration; the responder says **“I got you,”** thrusts one product into frame, and the first person says **“Thank you.”** That loop repeats six times in about 24 seconds. The pattern then breaks on the natural purchase objection—individual products look expensive—and the responder shifts to a bundle/value reveal and a downward-pointing purchase gesture.

| Source beat | Timing | Reusable job | Medicube constraint |
|---|---:|---|---|
| Pain point → “I got you” → product hand-off → “Thank you” | 0–24s | Builds pace through repeated, instantly legible problem/solution beats. | Use **three** component-specific beats, not six unrelated claims. The Bye-Bye Bumps set has three clearly identified components. |
| Pattern-break objection | 24–29s | Voices the buyer’s cost objection after value has visually accumulated. | Do not state a bundle price, “over $100” retail total, percentage saving, sale, or shipping promise without filming-day verification. |
| Bundle/value reveal + point to cart | 29–33s | Reframes individual purchase friction as a bundled-cart opportunity. | Show the exact current set and live cart. Say only what the cart/official component-price evidence supports that day. |

## 2. Recommended One-Person Execution

The format can work with one creator without pretending another person is present. Use a simple two-position role-play in the same room: the **viewer/patient-question role** leans in from frame left with an anxious, quick question; the **pharmacist role** remains centered/right, calm, and physically moves the relevant component toward the lens while saying **“I got you.”** A small prop, a half-turn, or a distinct posture is enough to differentiate the roles. The loop should be quick, but every hand-off must show a real product.

> If “my patients” accurately reflects real, ordinary counseling conversations, it can be used as the setup. Do not invent a specific patient, patient outcome, or purchase history for the skit. If the underlying premise is not literal, use “when people ask me” or “when someone tells me” while preserving the same rhythm.

## 4. Bundle Objection and Value-Reveal Logic

The original source uses a fixed individual-retail anchor: “just one of them cost $35.” The Medicube version should preserve the **objection → bundle resolution** logic but never guess the math.

| Beat | Candidate role-play language | Filming-day proof required |
|---|---|---|
| Cost objection | “But how am I supposed to buy a peel, a wash, and a lotion separately?” | No numeric claim required. Hold all three actual components. |
| Bundle reveal | “Maybe individually. But Medicube put the peeling step, the wash, and the lotion together in this one set—so you are not trying to build the routine piece by piece.” | Exact TikTok Shop set, current included components, and current seller/cart. |
| Optional savings line | “The current cart is showing the set for [current live price] versus [current verifiable individual total].” | Exact current official individual prices and exact live bundle cart captured immediately before filming. If either changes or is unavailable, omit this line. |
| Close | “If you want the full routine instead of trying to piece it together, the exact set is in the orange cart below.” | Product attached in the exact cart; use no scarcity/offer wording unless true that day. |

## 5. Pacing and Visual Plan

**Target runtime:** 35–50 seconds. Three loops give enough room for component-specific education without making the format feel like a slow routine walkthrough. Each pain-point line should take 1–2 seconds, each “I got you” hand-off 1 second, and each explanation 3–5 seconds. The price/value objection is the final pattern interrupt—not a fourth product pitch.

| Segment | Timing | Visual / overlay plan |
|---|---:|---|
| Opening and loop 1 | 0–8s | Start with Peeling Shot already in frame. Opening text: **“STRAWBERRY LEGS? I GOT YOU.”** for 3–5 seconds; product hand-off; small card: **“RINSE-OFF EXFOLIATING STEP.”** |
| Loop 2 | 8–16s | Body Wash hand-off and lather visual. Card: **“SHOWER CLEANSING STEP.”** |
| Loop 3 | 16–24s | Lotion hand-off and arm/body application visual. Card: **“LEAVE-ON MOISTURE STEP.”** |
| Mini routine board | 24–28s | Complete set together. Board populates: **1. PEEL → 2. WASH → 3. LOTION.** |
| Cost pattern-break | 28–34s | Question-role holds three items / gestures at them. No price overlay unless current evidence is visible. |
| Bundle reveal and cart close | 34–45s | Pharmacist role holds full exact set. Show current cart only if captured that day; orange arrow and physical downward point during CTA. |

## 6. Asset Classification and Required Gates

This is best classified as a **MOF bundle-value / routine-clarity asset** with a BOF-style bundle close. It is not automatically a substitute for the required Type 3 instruction-correction asset or any other campaign slot. It can sit alongside the standard Bundle Routine Walkthrough because the jobs differ: this format earns attention by rapid pain-point matching, while the active walkthrough teaches routine order in a slower, saveable sequence.

| Required gate | Status before scripting |
|---|---|
| Exact component set, directions, ingredient roles, and source boundaries | **Complete** in the Medicube fact record; retain the 220 mL vs. 230 mL lotion-size discrepancy. |
| Campaign placement and no-duplication decision | **Needs user approval.** Decide whether this is a first-wave MOF asset, a later conversion/value variant, or replaces another non-required format. |
| Component-specific proof cards | **Needs final filming plan.** Use label/official-direction proof only where each exact claim is spoken. |
| Truthful patient framing | **Needs creator confirmation** if literal “my patients” language is used. |
| Current individual-price / bundle-value language | **Needs filming-day verification.** Otherwise use the non-numeric “piece it together” version. |
| Exact current cart / offer | **Needs filming-day verification.** |

## 7. Recommendation

Approve this as a **new, product-specific candidate campaign asset** only if you want the rapid skit pacing and bundle-value reveal to test against the slower bundle walkthrough. Keep the three components in their distinct roles, make the full set the final visual payoff, and retain a non-numeric value reveal by default. Once the campaign placement and current cart facts are approved, this outline can become a final script with a complete post-production section.
